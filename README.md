# 🎓 AI Student Performance Analyzer

This project is a web-based AI application that analyzes student performance and predicts risk levels using Machine Learning.

## 🚀 Features
- Predicts academic risk using Logistic Regression
- Calculates placement probability
- Generates subject-wise analysis charts
- Creates automated PDF reports
- Sends reports via email
- Provides study timetable
- Daily & weekly tracking system

## 🧠 Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas, NumPy
- Plotly, Matplotlib
- ReportLab

## ▶️ How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the app:
   streamlit run app.py

## 📌 Note
This is a prototype model using sample data.
